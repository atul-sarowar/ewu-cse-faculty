# EWU CSE Faculty

A modern UI redesign for the **East West University (EWU) Computer Science & Engineering (CSE) Faculty Members** page.

This Chrome extension redesigns the faculty page directly in your browser without modifying the original EWU website or its server.

## ✨ Features

- 🎨 Modern and clean faculty card design
- 👨‍🏫 Faculty profile cards
- 🖼️ Faculty profile photos
- 🔤 Faculty initials displayed on cards
- 🔎 Search faculty by name or initials
- 🏷️ Filter faculty by designation
- 🌙 Dark mode
- 📱 Responsive design
- 🔗 Direct links to existing faculty profiles
- ⚡ Lightweight and runs locally in the browser

## 🌐 Supported Page

The extension works on:

**EWU CSE Faculty Members**

https://fse.ewubd.edu/computer-science-engineering/faculty-members

## 📦 Installation

### Method 1 — Chrome Web Store

Coming soon.

Once the extension is published on the Chrome Web Store, you will be able to install it directly with **Add to Chrome**.

### Method 2 — Install from GitHub

1. Go to the **Releases** section of this repository.
2. Download the latest `.zip` file.
3. Extract the ZIP file.
4. Open Chrome and go to:

   `chrome://extensions`

5. Enable **Developer mode**.
6. Click **Load unpacked**.
7. Select the extracted extension folder.
8. Open the EWU CSE Faculty Members page.
9. Refresh the page if necessary.

The redesigned interface should now appear automatically.
